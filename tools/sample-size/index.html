Sample Size & Margin of Error

Plan a survey: find how many responses you need for a margin of error you can accept, or check the margin of error for the number of responses you already have.

Confidence level

Use 50% for the expected proportion if you have no prior estimate. It gives the largest, safest sample size. Fill in the population size only when it is small or known (for example, all 800 students in a school).

How this was worked out

    This uses the normal approximation for a proportion from a simple random sample. It does not account for non-response, clustering or weighting. If you expect only some people to reply, divide the sample size by the response rate you expect.
