Classification Metrics

Enter a confusion matrix or paste gold and predicted labels. You get precision, recall and F1 for each class plus the usual averages, ready to paste into a paper.

Class names (optional)

Counts. Rows are the true class, columns are the predicted class.

Per-class results

Precision for a class that was never predicted is reported as 0, the same as scikit-learn's default. Micro F1 equals accuracy for single-label classification.
